# Analisis-de-Movilidad-urbana-y-productividad-economica-

**🏙️ Contexto del proyecto**

Relación entre la movilidad urbana y la productividad económica en las principales ciudades de Latinoamérica mediante la limpieza y transformación de datos con Python, integrando información de movilidad y economía para identificar oportunidades de inversión en infraestructura de transporte que impulsen la productividad y el bienestar.


**🎯 Objetivo del proyecto**

Integrar y analizar datos de movilidad urbana de TomTom y variables económicas de OECD para las principales ciudades latinoamericanas durante 2024, utilizando Python para identificar patrones entre congestión vehicular y productividad económica, y generar información que permita orientar futuras inversiones en infraestructura de transporte.


**💡 Preguntas del negocio:**

¿Qué ciudades presentan alta congestión y baja productividad económica?

¿Cuáles muestran los mejores indicadores combinados (movilidad eficiente y economía fuerte)?

¿Qué variables parecen tener una relación más fuerte con el desarrollo urbano?


**🗂️ Origen de Datos**

**🚦 Movilidad urbana:** Datos sobre congestión vehicular y condiciones de tráfico en ciudades del mundo. 

**💹 Economía urbana:** Indicadores económicos y ambientales por ciudad, recopilados por la OECD (Organización para la Cooperación y el Desarrollo Económico). 

**📅 Periodo de Analisis:** 2024


**🛠️ Herramientas de la lección**

Jupyter Notebook

Python: pandas, numpy, seaborn, matplotlib

-Resume los patrones más importantes entre índices de tráfico y PIB per cápita.

-Destaca anomalías u outliers que podrían requerir revisión adicional o un análisis más profundo.

-Se observa una relación inversa moderada entre el índice de tráfico y el PIB per cápita: las ciudades con mayor congestión tienden a registrar menores niveles de productividad económica. Sin embargo, se identificaron algunos valores atípicos, donde ciudades con alta congestión mantienen un PIB per cápita relativamente alto, por lo que se recomienda profundizar el análisis incorporando variables como inversión pública, crecimiento poblacional y calidad del transporte.


**📝 Recomendacion**

-Se recomienda priorizar inversiones en infraestructura de transporte y movilidad sostenible en las ciudades con mayor congestión. Entre ellas, Bogotá presenta la relación más significativa entre altos niveles de tráfico y menor productividad económica, por lo que se identifica como la principal ciudad para intervenir. Asimismo, es conveniente validar periódicamente las fuentes e incorporar variables como empleo, crecimiento poblacional y uso del transporte público para fortalecer futuras decisiones.
